# docs/adr: architecture decision records

One file per decision: `adr-NNN-slug.md`, numbered in order, never renumbered or deleted. Copy [`adr-000-template.md`](adr-000-template.md).

- A replaced decision keeps its file and gets `Status: superseded by ADR-NNN`.
- ADR-001 to ADR-010 are Mid-1 deliverables (titles in master plan section 25). Two members review each ADR.
- The report's design chapter links to the ADRs instead of repeating them.
