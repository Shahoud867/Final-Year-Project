# Finding state machine

Generated by `python scripts/export_diagrams.py` from the code. Do not edit by hand; a CI check fails if it drifts.

Every change of a finding's status goes through `granite_core.lifecycle.transition`; an event that is not listed here for the current status raises an error and the API answers 409 with the allowed actions. The levels V0 to V3 follow from the status (`verification_level`).

```mermaid
stateDiagram-v2
    [*] --> open
    open --> hypothesized: hypotheses_ready
    hypothesized --> verifying: verify_started
    hypothesized --> evidence_supported: evidence_supported
    verifying --> confirmed: verdict_confirmed
    verifying --> refuted: verdict_refuted
    verifying --> inconclusive: verdict_inconclusive
    verifying --> hypothesized: verify_error
    refuted --> verifying: verify_started
    inconclusive --> verifying: verify_started
    confirmed --> accepted: review_accept
    confirmed --> rejected: review_reject
    inconclusive --> accepted: review_accept
    inconclusive --> rejected: review_reject
    evidence_supported --> accepted: review_accept
    evidence_supported --> rejected: review_reject
    accepted --> resolved: resolve
    accepted --> wont_fix: wont_fix
    rejected --> [*]
    resolved --> [*]
    wont_fix --> [*]
```
