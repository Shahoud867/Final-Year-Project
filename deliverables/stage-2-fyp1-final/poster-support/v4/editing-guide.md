# Editing and presentation files

Install the supplied fonts first.

- **Photoshop:** open `granite_poster_fyp1-final_v4.0.psd`. It contains 110 live text layers. Artwork is stored in named embedded vector PDF smart objects; use the source SVG for direct vector-path editing in a vector editor. Keep the Background group separate for future revisions.
- **CorelDRAW / vector editors:** open the main live-text SVG, or a section SVG from `sections`. Check text/fonts, layout and page size after import, then save to the application's native format. A native CDR is not claimed.
- **Printing/viewing:** use the vector PDF or the 6750 × 10350 px / 300-ppi JPEG. The main poster has exact trim dimensions; no unconfirmed bleed is included.
- **Presentation/report figures:** `sections` contains independent opening/team, architecture, evidence and stack SVG/PDF/PNG files. The PNGs are presentation previews; use vectors for resizing and print quality.
- **Figma:** the Figma import SVG uses outlined vector text. The optional local importer creates live text, but has not been executed in the live file. The original Figma link is not the current v4.0 artwork.

A Photoshop cloud edit link is created by saving the PSD to the user's Adobe cloud account and granting editing access. These download files are not an Adobe/Corel cloud collaboration link.
