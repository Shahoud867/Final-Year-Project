# System test cases

Generated by `python scripts/build_test_docs.py` from the docstrings of [`tests/system/test_system.py`](../../tests/system/test_system.py). Do not edit by hand: every case below is an executable test, and CI fails if this file is out of date.

**Level:** system (black box). The suite starts the real server as a separate process and uses only HTTP, the way the web UI or a script reaches it. Model answers come from the recorded cassette, so results are deterministic and need no model. Unit and integration tests live next to the code they test (`packages/*/tests`, `workflows/*/tests`, `apps/api/tests`, `apps/web/tests`).

**Run:** `pytest tests/system` from the repository root. To test a server that is already running (a container or a deployed instance): `GRANITE_SYSTEM_BASE_URL=https://host pytest tests/system`; cases marked *own server* need to configure the server themselves and are then skipped.

**Cases:** 22 in 4 groups. Latest recorded results: see `evidence/reports/`.
