# Official technology artwork

These marks identify technologies used by Granite. Original vendor artwork is retained alongside the exported emblem components. Geometry was not redrawn. The JSON records source URLs, checksums and component extraction.

- **Python**: https://www.python.org/static/community_logos/python-logo-generic.svg — Exact emblem paths and original paints isolated from official combined logo; no freehand redrawing.
- **FastAPI**: https://raw.githubusercontent.com/fastapi/fastapi/master/docs/en/docs/img/logo-teal.svg — Exact icon group isolated from official teal wordmark; source geometry and colours retained.
- **React**: https://raw.githubusercontent.com/reactjs/react.dev/main/public/images/brand/logo_dark.svg — Complete official mark; proportionally scaled.
- **TypeScript**: https://raw.githubusercontent.com/microsoft/TypeScript-Website/v2/packages/typescriptlang-org/static/branding/ts-logo-512.svg — Complete official square mark; proportionally scaled.
- **Ollama**: https://raw.githubusercontent.com/ollama/ollama/main/docs/ollama-logo.svg — Complete official mark; proportionally scaled.

Vendor artwork retains its original colours. The Python emblem retains its original native gradient; no gradient or effect was added to the poster background or diagrams.
