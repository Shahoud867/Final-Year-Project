# research

Knowledge and experimental evidence behind the product (active). The papers themselves are in [`references/papers/`](../references/papers/) and datasets in [`data/`](../data/).

| Folder | Holds |
|---|---|
| `literature/` | notes on papers and on the baseline; each note says which design decision it influenced |
| `market/` | commercial and framework comparisons (re-check vendor documentation before every gate) |
| `spikes/` | proposal-stage proof-of-concept experiments: scripts, outputs, inputs |
| `eval/` | pre-registered evaluation, FYP-1 final onward |
