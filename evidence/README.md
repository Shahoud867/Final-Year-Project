# evidence

Append-only proof that something happened. The Mid-1 rubric asks for "live evidence" behind every claim. Subfolders are created on first use; their names are fixed:

| Folder | Holds |
|---|---|
| `repo/` | screenshots of branch protections, pull requests, CI/CD runs, tags, project board |
| `interviews/` | stakeholder interviews: who (with consent), when, what changed in the requirements |
| `uat/` | acceptance sessions, consent forms, tasks and results |
| `demos/` | screenshots and recordings of the working system |
| `reports/` | exported test, coverage, evaluation and security-scan reports |

Name files `YYYY-MM-DD_slug.ext`. Cite each file from the register or report section that depends on it. Participant consent is required before storing any recording or data.

Video stays on OneDrive and is git-ignored here (`.gitignore`); list each recording below so it can be found.
