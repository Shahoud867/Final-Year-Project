# docs/diagrams

Diagram sources and their exports side by side, one base name per diagram, named by what it shows (`finding-state-machine.mmd` + `finding-state-machine.pdf`). Sources are Mermaid (`.mmd`), PlantUML (`.puml`) or draw.io (`.drawio`); the report uses the exported PDF/PNG.

- Required set for Mid-1 and who draws what: master plan section 25.
- Every diagram must match the code at the tagged commit it ships with. Mark unbuilt parts "planned".
- Each diagram needs 3-6 lines of project-specific explanation where it is used (rubric Form 3, criteria 5 and 6).
