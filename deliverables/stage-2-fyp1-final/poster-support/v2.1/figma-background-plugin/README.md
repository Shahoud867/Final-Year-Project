# Apply the background to the original Figma frame

The direct Figma editor hit the account's Starter-plan call limit during this task. This optional local plugin applies the complete prepared background to the original frame **31:3**, preserving its native text. It was prepared and syntax-checked, but **has not been run in Figma**.

In Figma Desktop: Plugins → Development → Import plugin from manifest, select `manifest.json`, then run **Granite — Apply Strata and Fault** in the linked Granite file. It uses no network access. The file must still contain the original frame and six section IDs; otherwise it stops before changing the canvas. Undo once to revert the run.

The existing text strings, fonts, sizes, colours, spacing, positions and section bounds are checked before and after the change. Background and Content panels are separate absolute containers behind the existing six sections. The two superseded decorative rules are hidden, not deleted. Four dots follow the thread; the final two are on the right. After applying, inspect the complete poster in Figma before exporting.

For a font-independent standalone vector copy, drag the supplied `granite_poster-figma-import_fyp1-final_v2.1.svg` into the same file. Its text is outlined; use the original frame or PSD for live text editing.
