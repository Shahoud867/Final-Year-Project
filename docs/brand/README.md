# brand

Draft visual identity for Granite. The concept mark is used in the interface (`BrandMark` in `apps/web/src/components/ui.tsx`, the favicon in `apps/web/index.html`) and on the poster since 2026-11-15; the team has not formally approved it.

| File | What it is |
|---|---|
| [`granite-logo-brief.md`](granite-logo-brief.md) | Analysis, three concepts, the selected "Fault Line" construction, colour, typography, checklist and a master prompt for a designer or AI tool |
| [`granite-mark-concept.svg`](granite-mark-concept.svg) | The proposed mark in full colour (concept geometry, verified by rendering) |
| [`granite-mark-concept-mono.svg`](granite-mark-concept-mono.svg) | The same in one colour |
| [`granite-favicon-concept.svg`](granite-favicon-concept.svg) | The bolder small-size version on an ink tile |

If the team chooses a different mark, replace `BrandMark` and the favicon; see the brief, section 9, item 12.
