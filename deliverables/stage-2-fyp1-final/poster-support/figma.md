# Editable Figma poster

https://www.figma.com/design/0OR9RnQzzZCGVfZWOulZ73?node-id=3-2

Granite FYP-1 final v1.1, BS (DS). Contains 146 editable text nodes, editable vector diagrams and charts, seven named content bands, and the repository university logo. Inter and JetBrains Mono are used.

Figma text metrics differ slightly from the print master; the three idea-card captions have fitted tracking. Use the supplied PSD/JPEG/PDF for the checked print dimensions and consult print-review.md before submission.
