# docs/manuals

The manuals the handbook requires, written so a person outside the team can install and operate Granite from a clean machine (handbook C.1.2):

| File | Content |
|---|---|
| `setup-manual.md` | configuration and setup: requirements, install, environment variables, first run |
| `tool-manual.md` | how to use the tooling: CI, tests, scripts, evaluation, deployment |
| `user-manual.md` | how an end user performs the core journeys |
| `handover.md` | FYP-2 final: source, build and run, dependencies, licences, credentials handling, known limits |

Each manual is tested by a non-owner before a milestone and linked from the report (implementation chapter). The rubric marks implementation documentation down if setup is not reproducible.
