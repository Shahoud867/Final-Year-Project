## Print and application completion steps

1. Print the crop PDFs at **Actual size / 100%**, with Fit/Shrink disabled. Read text from one metre and check the faint background on the actual printer.
2. Install the supplied fonts and open the PSD in Photoshop. Native structure and cached rendering have passed digital checks; a Photoshop application open test has not been performed.
3. Confirm printer bleed, colour profile and delivery settings. Artwork is exact trim size, sRGB, with no unconfirmed bleed. The handbook assigns printing responsibility to groups using other authoring tools.
4. Obtain supervisor approval before committee acceptance and submit the source file plus JPEG by the coordinator's announced deadline.
5. Figma remains at the older revision: the account's Starter-plan direct-edit tool limit blocked the new import. The included native-text importer was syntax-checked but has not run in Figma; inspect it after applying. This synchronization is separate from handbook submission requirements.
